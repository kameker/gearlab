# GearLab 1.0 — конструктор шестерён для Windows

Распакуйте весь архив и запустите **GearLab.exe**. Папка `_internal` должна оставаться рядом с EXE. Установка Python и интернет не нужны. Windows 10/11, 64 бита; для 3D-вида нужен рабочий графический драйвер с OpenGL. Программа проверена на этом Windows-компьютере; на других конфигурациях отдельной проверки не было.

## Создание модели

1. Выберите тип: прямозубая, косозубая, шевронная, с внутренними зубьями, рейка, предварительная коническая или червяк-винт.
2. Укажите число зубьев (6–300), модуль или наружный диаметр, высоту, угол профиля и направление наклона. Для косозубого профиля задаётся **нормальный модуль**. Для червяка — осевой модуль и число заходов.
3. На вкладке «Отверстие» задайте круг, D-профиль с лыской либо шестигранник. У шестигранника размер измеряется между гранями. Ноль отключает сквозное отверстие. Расточка начинается от верхнего торца; ноль в её диаметре или глубине отключает расточку. При сквозном диаметре 0 расточка становится глухим карманом.
4. Модель пересчитывается после изменения значения стрелками или подтверждения ввода Enter. Ошибочные размеры скрывают старую модель и отключают экспорт. Боковой зазор уменьшает толщину зуба на делительной окружности; это не припуск отверстия.
5. Экспортируйте STL для слайсера либо STEP для КОМПАС и других CAD. Выбранная точность влияет на STL и просмотр; STEP сохраняет кривые и поверхности отдельно от треугольной сетки.

Все размеры в миллиметрах. STL не содержит записи единиц, поэтому в слайсере выбирайте миллиметры. «Сохранить» записывает редактируемый проект `.gearlab`; это JSON, а не STL/STEP.

«Ø впадин вручную» = 0 включает стандартную высоту ножки 1,25 модуля. Ненулевое значение фиксирует измеренный диаметр: при изменении зубьев или модуля его тоже нужно проверить либо обнулить.

## Управление просмотром

Левая кнопка мыши — вращение; колесо — масштаб; Shift + левая кнопка — сдвиг. Кнопки «Изометрия», «Сверху», «Спереди» заново вписывают модель в окно. «Каркас» показывает сетку. «Разрез» разрезает только отображение; файл экспортируется целиком. Сетка лежит в плоскости XY, ось шестерни направлена по Z. Цвет и освещение не входят в STL/STEP.

## Примеры 12T, 36T и 48T

В списке сверху есть 12T, 36T и 48T. Сохранены исходные параметры: высота 10 мм, отверстие Ø2,8 мм; у больших шестерён расточка Ø10 × 5 мм. У малой: наружный Ø7,8 мм, диаметр впадин 5,5 мм. Нормальный модуль 0,5280927299414034 мм, угол профиля и наклон по 20°. Оба угла были **приняты**, а не измерены по фотографии.

Для цепочки на параллельных валах **12 левая → 48 правая → 48 левая**. Модуль, угол профиля и величина наклона у сопряжённых шестерён должны совпадать. Общая передача 12 → 48 → 48 равна 4:1. При неизменённом модуле расстояния между осями: 12/48 — 16,859536 мм; 48/48 — 26,975258 мм. Пресеты не заменяют проверку контакта с реальной деталью.

## Геометрические ограничения

Боковые поверхности цилиндрических зубьев строятся по эвольвенте. В сетке используются дискретные сечения, в STEP — интерполированные кривые и винтовые поверхности OCCT. Ниже основной окружности профиль продолжен радиально. Не моделируются подрезание инструментом, корневая галтель, фаски, коррекция профиля, точность по стандартам, напряжения и контакт пары. Из-за этого шестерня с малым числом зубьев требует особой проверки. Число 6 — предел ввода, а не гарантия отсутствия подрезания.

Коническая модель — эскизный профиль из масштабированных эвольвентных сечений; это не точный расчёт сопряжённых конических зубьев. Червяк — трапецеидальный винт; ответное червячное колесо не генерируется. У внутренней передачи интерференция пары не проверяется. Рейка прямозубая; отверстия к ней не применяются.

Для печати выбирайте материал, допуски и разрешение под свой принтер. В пресетах не добавлен скрытый припуск отверстий. Проверьте малую пробную печать и свободное вращение до установки под нагрузку. Импорт существующих STEP/STL, сборка в КОМПАС, произвольная форма зуба и расчёт полного редуктора в эту версию не входят.

## Проверка выпуска

Автотесты проверяют семь семейств, направления наклона, размеры исходной 12T, объём ступенчатого отверстия, восстановление параметров и отбраковку ошибок. STL повторно читается и проверяется на открытые/немногообразные рёбра и число компонент. STEP повторно открывается OCCT, проверяется валидность твёрдого тела и сравнивается объём с сеткой. Отдельно проверяются изменения через виджеты, восстановление проекта, восстановление после ошибки, разрез и экспорт. В EXE встроен режим `--smoke-test <папка>`, который проверяет окно, пресеты и оба экспорта, затем закрывается. Это проверки геометрии и работы программы, а не испытания ресурса передачи. Независимая проверка в FreeCAD и физическая печать не выполнялись.

## Исходный код и сборка

Исходный код находится в отдельном архиве. В обычной Python 3.12 x64 среде:

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
.venv\Scripts\python -m pytest tests -q --basetemp=build-test-tmp
.venv\Scripts\python -m PyInstaller --noconfirm GearLab.spec
.venv\Scripts\python package_release.py --output release
```

Программа не отправляет параметры и файлы в сеть. Журнал ошибки запуска — `%LOCALAPPDATA%\GearLab\error.log`. Данные сохраняются только по выбранному вами пути.

## Компоненты и источники

Интерфейс — PySide6/Qt, визуализация и сетки — VTK, вычисления — NumPy, STEP — Open CASCADE через OCP, упаковка — PyInstaller. Лицензии сторонних компонентов включены в папку `licenses`; библиотеки поставляются отдельными динамическими файлами. Исходники приложения доступны для изменения и повторной сборки.

Документация: [Qt for Python / Deployment](https://doc.qt.io/qtforpython-6/deployment/index.html), [VTK QVTKRenderWindowInteractor](https://docs.vtk.org/en/v9.6.1/api/python/vtkmodules/vtkmodules.qt.QVTKRenderWindowInteractor.html), [KG Gear: расчёт косозубой передачи](https://www.kggear.co.jp/en/wp-content/themes/bizvektor-global-edition/pdf/9.3_Calculation-for-the-Normal-standard-helical-gear_TechnicalData_KGSTOCKGEARS.pdf), [KHK: внутренние передачи и интерференция](https://khkgears.net/pdf/internal-tech.pdf).
